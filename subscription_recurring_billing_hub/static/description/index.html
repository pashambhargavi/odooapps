Frequently Asked Questions

Does this require Odoo Enterprise?

No! This module is built specifically for Odoo 19.0 & 18.0 Community Edition. It runs 100% natively without needing any paid Enterprise license or external third-party subscriptions.

Does it support Multi-Company environments?

Yes. Multi-company record security rules are built in. Each subsidiary company can configure its own distinct recurring plans, currency rates, and contracts safely.

How does automated invoicing work?

An automated Odoo cron scheduler runs daily in the background. It finds all active contracts due for billing, generates customer invoices, steps forward the next billing date, and posts an audit note to chatter.

Can we customize payment gateways (Stripe / PayPal)?

Yes! Invoices generated by this hub use standard Odoo Customer Invoices (`account.move`), so any payment provider configured in your Odoo database is immediately supported.
