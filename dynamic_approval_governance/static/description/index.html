Quick Configuration & Workflow Guide

1. Configure Approval Categories

Navigate to Smart Approvals → Configuration → Approval Categories. Choose which fields (Date, Period, Amount, Quantity, Contact, Location, Product Lines, Attachments) are Required, Optional, or Hidden, and assign default multi-tier approvers.

2. Set Up Dynamic Matrix Rules

Navigate to Smart Approvals → Configuration → Dynamic Matrix Rules. Select the target document (Sales Order, Purchase Order, Customer Invoice, or Vendor Bill), configure amount/discount thresholds, and add sequential or parallel approval tiers.

3. Automatic Transaction Interception

When a user clicks Confirm on a Sales/Purchase Order or Confirm/Post on an Invoice/Bill that matches a rule, the document automatically enters Waiting for Approval and notifies Tier 1 approvers.

4. Approve, Refuse & Auto-Confirm

Approvers review pending items from Smart Approvals → Document Approval Queue or directly on the document form. Once the final tier approves, the order or invoice is automatically confirmed/posted.
