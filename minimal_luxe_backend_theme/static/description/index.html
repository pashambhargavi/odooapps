QUALITY ASSURANCE PLAYBOOK

7-Step Verification & Testing Runbook

Follow this comprehensive sequence to verify all features in under 3 minutes.

Step 1: Install Addon & Observe Monochromatic Login

Install minimal_luxe_backend_theme. Log out to inspect the Apple-style split-screen login page with clean typography and hairline borders.

Step 2: Inspect Linear Obsidian Canvas

Log into the backend. Observe the deep obsidian dark background (#09090B), razor-thin 1px hairline dividers, and sovereign gold button accents.

Step 3: Toggle Zen Focus Mode in Systray

Click the eye icon in the top-right systray. Notice how the navigation bar smoothly dims into the background, giving 100% focus to the active document.

Step 4: Cycle Luxury Metal Accents via Systray

Click the diamond icon in the top-right systray to cycle dynamically between Sovereign Gold, Pure Titanium, Platinum Ice, Emerald Mint, and Rose Gold.

Step 5: Verify Tabular Financial Ledger Alignment

Open Accounting Journal Items list view. Confirm that monetary numbers render with JetBrains Mono tabular spacing and sticky table headers.

Step 6: Test Mobile Viewport & OLED Pure Black

Switch browser to mobile simulation (iPhone/Android). Verify the clean distraction-free mobile navigation bar with responsive tap targets.

Step 7: Configure Settings in Minimal Luxe Studio

Navigate to Settings > Minimal Luxe Studio. Configure company-wide metal presets, hairline border profiles, and typography suites.
