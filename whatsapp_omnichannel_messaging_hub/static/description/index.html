Frequently Asked Questions

Does this require a paid Meta WhatsApp API subscription?

No! This module uses direct click-to-chat deep linking, which opens WhatsApp Web, WhatsApp Desktop, or your WhatsApp Mobile app instantly with pre-filled messages. Zero API costs and no credit card required.

Does it work on both Odoo 19.0 and Odoo 18.0?

Yes! Fully tested and verified across both Odoo 19.0 and 18.0 Community and Enterprise editions with clean, PEP8-compliant Python code.

Can I create custom templates for other departments?

Yes! Under WhatsApp → Configuration → Templates, you can create unlimited templates for any model with rich dynamic variables and default message texts.

How are phone numbers formatted?

The composer wizard automatically cleans customer phone numbers by removing spaces, dashes, parentheses, and leading plus signs, ensuring clean compliance with international WhatsApp standards.
